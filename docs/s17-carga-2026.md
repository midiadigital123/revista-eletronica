### 6b. Criar e mandar o link de senha

Monte `~/usuarios-2026.csv` (fora do git) com o cabeçalho `usuario,grupo`. Grupos aceitos:
`Admin`, `Pedagógica`, `Mídias Digitais`, `Impresso`. Exemplo de formato:


```bash
docker compose run --rm -v ~/usuarios-2026.csv:/tmp/usuarios.csv:ro app \
  python manage.py criar_usuarios /tmp/usuarios.csv --url http://localhost:8000
```

- **Esperado:** uma linha por usuário, `criado (<grupo>): <usuario> http://…/conta/senha/<uid>/<token>/`.
  Uma linha com grupo errado recusa o arquivo inteiro sem criar ninguém.
- O usuário nasce com senha inutilizável, `is_staff` e o grupo. O link é do próprio Django
  (`PasswordResetConfirmView`): vale 3 dias e uma vez só. Mande cada link em particular:
  ele dá acesso à conta.
- Sem envio por e-mail: o sistema não tem SMTP configurado. Quando tiver (`EMAIL_HOST`),
  o comando pode mandar o link em vez de imprimir.
- Link vencido: rode o mesmo comando. Quem ainda não definiu senha ganha link novo;
  quem já definiu aparece como `já existe, mantido` e não é alterado.
- **Conferir:** `/admin/auth/user/`, filtro lateral "grupos": cada um dos 4 grupos lista quem
  deve estar lá.
